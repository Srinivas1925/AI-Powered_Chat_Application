# AI-Powered Chat Application


## Description 
A real-time AI chatbot that leverages Google Gemini API to provide dynamic conversational responses with seamless backend-frontend integration. Perfect for interactive chat experiences with minimal latency.

## Features
- Real-time chat between user and AI  
- Dynamic responses powered by Google Gemini API  
- Interactive and responsive UI  
- Auto-scroll chat window  
- Retry mechanism for API overload errors  

## Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Flask (Python)  
**AI Integration:** Google Gemini API
